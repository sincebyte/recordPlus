开发一个 macOS 原生窗口录制应用，用于捕获单个应用窗口并以 Chroma Key 方式生成带透明通道（Alpha Channel）的视频素材，最终生成可直接导入 DaVinci Resolve / Final Cut Pro 的 ProRes 4444 视频文件。

## 可行性分析

### ScreenCaptureKit 的 Alpha 能力

核心结论：macOS 的 WindowServer 在合成窗口到显存缓冲区时已丢失 Alpha 信息。ScreenCaptureKit 捕获的是合成后的最终画面，即使使用 BGRA 像素格式，Alpha 字节始终为 =0xFF=（完全不透明）。无法直接获取原生 Alpha 通道。

### 解决方案：Chroma Key（色键抠像）

Chroma Key 是一种视频合成技术：指定一个关键色（Key Color），将画面中所有该颜色的像素替换为透明，其余像素保持不透明。

本项目利用 =SCStreamConfiguration.backgroundColor= 属性，将窗口外区域填充为指定颜色（如品红色 =#FF00FF=），然后通过 GPU Shader 将该颜色像素的 Alpha 设为 0，窗口内容像素 Alpha 保持 1，从而生成 Alpha 通道。

原理流程：

```
┌──────────────────────────────────────────────────────────────┐
│  SCStream 单窗口捕获                                          │
│  backgroundColor = 品红色 (#FF00FF)                           │
│  窗口外区域 → 品红色  窗口内容 → 原始画面                      │
│                         │                                    │
│                         ▼                                    │
│  CMSampleBuffer → CVPixelBuffer (BGRA, Alpha=0xFF 全不透明)   │
│                         │                                    │
│                         ▼                                    │
│  Metal Compute Shader (Chroma Key)                            │
│  检测品红色像素 → 设 Alpha=0                                 │
│  非品红色像素   → 设 Alpha=1                                 │
│  边缘过渡像素   → 按距离做 Alpha 渐变                         │
│                         │                                    │
│                         ▼                                    │
│  CVPixelBuffer (BGRA, 带真实 Alpha 通道)                      │
│                         │                                    │
│                         ▼                                    │
│  AVAssetWriter → Apple ProRes 4444 (yuva444p10le)            │
└──────────────────────────────────────────────────────────────┘
```

### 为什么选品红色 (#FF00FF)

终端、代码编辑器、浏览器中几乎不会出现品红色（=R=255, G=0, B=255=），最大程度避免误判。如果用户窗口内容确实包含品红色，可配置其他关键色（如绿色 =#00FF00=）。

### 与 OBS 方案的对比

| | OBS | 本项目 |
|------|------|------|
| Alpha 生成方式 | Chroma Key 滤镜 | Metal Compute Shader（自定义） |
| 窗口捕获 | ScreenCaptureKit | ScreenCaptureKit |
| 编码器 | 第三方 ProRes 编码器 | AVFoundation 原生 |
| 性能 | 中等 | 更优（Metal GPU 加速，零拷贝） |
| 可定制性 | 低 | 高（完全可控的 Shader 管线） |

### 3. Chroma Key Alpha 生成

这是核心需求。通过 Metal Compute Shader 从指定背景色生成 Alpha 通道。

最终输出的帧数据必须为：

```
BGRA

B: Blue
G: Green
R: Red
A: Alpha
```

窗口外区域：

```
Alpha = 0  (完全透明)
```

窗口内容：

```
Alpha = 1  (完全不透明)
```

窗口阴影边缘：

```
Alpha 渐变 (0.0 ~ 1.0)
```

需要支持：

* 圆角窗口 → 边缘反锯齿 Alpha 渐变
* macOS 阴影 → 半透明 Alpha 梯度
* 窗口内容半透明区域 → 保留原始透明度（需特殊处理，见下文）

**Chroma Key Shader 逻辑：**

```
对于每个像素，计算其与关键色 (keyColor) 的距离：

  distance = sqrt((R - keyColor.R)² + (G - keyColor.G)² + (B - keyColor.B)²)

  if distance < threshold_low:
      alpha = 0.0        // 完全匹配 → 透明
  elif distance > threshold_high:
      alpha = 1.0        // 窗口内容 → 不透明
  else:
      alpha = (distance - threshold_low) / (threshold_high - threshold_low)  // 渐变过渡
```

**半透明区域处理：**

如果窗口内容本身包含半透明区域（如终端背景的半透明模糊效果），应在 Chroma Key 之前先捕获一层黑色背景帧，再捕获一层白色背景帧，通过两次捕获的差异推算真实 Alpha。此为进阶功能，初期可实现基础 Chroma Key，后续迭代加入。

**可配置参数：**

* =keyColor=: 关键色（默认 =#FF00FF= 品红色）
* =threshold=: 颜色匹配阈值（默认 =0.1=）
* =smoothness=: 边缘平滑度（默认 =0.05=）

### 10. 调试验证

使用 ffprobe 检查输出文件：

正确：

```
codec_name=prores
pix_fmt=yuva444p10le
```

错误：

```
pix_fmt=yuv420p   (丢失 Alpha)
```

在 DaVinci Resolve 中确认 Alpha 通道：

1. 导入 =output.mov= 到 Media Pool
2. 拖入 Timeline
3. 在 Timeline 中右键片段 → =Clip Attributes → Video=
4. 确认 =Alpha Mode= 为 =Premultiplied= 或 =Straight=
5. 在片段下方放置一个彩色背景
6. 窗口外区域应显示背景色，窗口内容应正常显示
